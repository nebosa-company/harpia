# Calibration bench collector

One bench session looks like this: reset the collector, import the run
files one after another, then print the report and the sample total. The
technicians run several sessions back to back in the same shell, so the
reset between them has to actually clear everything.

The per-group numbers have always looked right, which is why nobody has
gone digging.
