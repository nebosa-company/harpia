Frequently asked questions

How long does a restore take?

A restore of the most recent snapshot completes in under ten minutes for projects below 50 GB. Larger projects are streamed and stay readable while the restore runs.

Can I move a project between organisations?

Yes, from the project settings page. Membership is not carried across; everyone who needs access has to be invited again on the other side.

What happens when a trial ends?

The project becomes read-only for thirty days. Nothing is deleted in that window, and adding a payment method restores write access immediately.

Getting started

Download the CLI for your platform and put it on your PATH. The installer does not need administrator rights and writes only to your home directory.

Run the login command once per machine. Credentials are stored in the operating system keychain, never in a dotfile.

Point the CLI at a directory and it uploads, builds and promotes in one step. Every deploy is addressable by its commit for the next ninety days.
