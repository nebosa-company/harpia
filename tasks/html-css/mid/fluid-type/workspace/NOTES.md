# Project notes

Typography layer shared by every property. The scale has to interpolate with
the viewport instead of stepping at breakpoints, and it has to bottom out and
top out at values the brand team signed off.

No pixel font sizes anywhere; the whole point is that the user's own text-size
preference keeps working.
