Type specimen

Every property draws its sizes from this one scale. The specimen exists so the steps can be compared side by side at any viewport width.

Headings

Headings run four steps above the body size. Nothing on any page sets a font size of its own.

Subheadings

The third step is the smallest heading that still reads as a heading in a dense document.

Minor headings

One step above the body size, used for card titles and table captions.

Footnotes, captions and legal text sit one step below the body size and never smaller.
