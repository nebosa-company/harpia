Questions

Does Halyard need access to our source?

No. Halyard reads build metadata and artefacts; the repository stays where it is.

Can we run it on our own hardware?

Self-hosted runners are part of the Enterprise plan, and the control plane can be pinned to one region.

What happens to a release we roll back?

It stays addressable. Rolling back promotes the previous artefact rather than deleting the current one.

How long is the trial?

Thirty days, with no card. At the end the project becomes read-only rather than disappearing.
