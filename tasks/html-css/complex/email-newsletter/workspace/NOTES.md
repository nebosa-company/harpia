# Project notes

Monthly newsletter template for the email service provider. It has to survive
Outlook's word-processor rendering engine, which means tables, attribute
widths and inline styles — none of the layout we use on the web.

The ESP substitutes `{{...}}` placeholders at send time; leave them literal.
