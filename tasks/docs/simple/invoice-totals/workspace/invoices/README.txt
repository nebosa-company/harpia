Invoices are dropped here as flat text by the billing mailbox rule. The
layout has not changed since 2019: a header block, a "Line items" block
whose rows are "qty unit description", then a Discount and a Tax line.

A line item whose description ends with "(void)" was cancelled after the
invoice was drafted. The line stays on the document for the audit trail
but it is not billed and must never reach a total.

This README is not an invoice.
