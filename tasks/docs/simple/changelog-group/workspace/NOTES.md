# Release notes notes

The changelog is the only release artefact anyone outside engineering
reads, so it gets written from the log rather than from memory. Release
commits are bookkeeping and have never belonged in it.

Conventional-commit subjects have been enforced by a hook since v1.0, so
the type and scope are trustworthy. The `!` marker is rare and always
deliberate: it means somebody's integration will break.
