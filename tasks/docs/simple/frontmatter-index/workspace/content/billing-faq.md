# Billing FAQ

**Why did my invoice change mid-cycle?** Because a seat was added. Seat
changes prorate to the day, and the proration line is always shown
separately.

**Can I get an invoice re-issued?** Yes, within the same tax year. After
that it needs a credit note instead.
