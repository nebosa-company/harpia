# Mobile Release Process

Store review takes between one and four days and cannot be hurried, so
the release branch cuts on Tuesday for a Friday submission.

Hotfixes skip the branch cut but never skip the staged rollout: five
percent, then fifty, then everyone, with at least twelve hours between
stages.
