# Onboarding

Week one is deliberately slow. New engineers pair for four days before
they touch a repository on their own, and the first change they ship is
always a documentation fix so the release path is familiar before it
matters.

Accounts are created from the starter ticket, never ad hoc. If an account
is missing on day one, the starter ticket was filed late.
