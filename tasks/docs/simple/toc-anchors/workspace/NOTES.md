# Handbook notes

The handbook is one long page on purpose — people search it with
ctrl-F and link each other to specific sections, so splitting it would
break every link anyone has ever pasted into a channel.

Three sections happen to share a heading, which is fine for readers and
awkward for anchors. The renderer resolves the collision by numbering
repeats in document order, and any table of contents has to agree with
it or the links land in the wrong place.
