# API reference notes

The reference is generated by hand and reviewed against the source at
each release. The rule that has kept it honest is coverage: a public
symbol with no entry is a bug in the document, and an entry for a symbol
that is not public is worse, because somebody will depend on it.

Anything whose name begins with an underscore is internal, including
module-level helpers and constants.
