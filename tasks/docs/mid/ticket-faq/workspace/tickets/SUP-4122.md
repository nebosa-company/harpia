# Export download link had expired by the time we tried it

## Customer

"The export finished on Friday afternoon, we picked it up on Tuesday and
every link is dead. Do we have to run the whole thing again?"

## Resolution

Export links are valid for 72 hours from the moment the export finishes,
after which the stored archive is deleted. A weekend is long enough to
run past that, which is what happened here.

Re-running the export is the only option; there is no way to revive an
expired link. Suggested scheduling long exports for Monday, and noted
that the completion email states the expiry time.
