# Request for a custom role between member and admin

## Customer

"We want a role that can manage users but not billing. Right now the
only way to let someone add colleagues is to make them an admin, which
also gives them the invoice history."

## Resolution

Reasonable request, and it has been asked for before. The role model is
deliberately two-tier and splitting it is a product decision rather than
a support one.

Closed as wontfix and linked to the existing product request so the
customer is counted on it. Nothing here is a supported behaviour today.
