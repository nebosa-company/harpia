# Cannot remove an admin from the workspace

## Customer

"We are tidying up roles and the console refuses to let me demote the
last person with the admin role. The error is not very clear."

## Resolution

Expected behaviour. An account must keep at least one admin at all
times, so the console refuses to demote or remove the final one. The
error message is genuinely unhelpful and a copy change has been filed
separately.

The customer's actual goal was to hand the role to someone else, which
works fine: promote the incoming admin first, then demote the outgoing
one.
