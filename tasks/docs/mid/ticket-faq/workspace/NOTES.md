# Support knowledge base notes

Tickets are the only written record of how a question was actually
answered. The FAQ is what we hand to customers before they open a
ticket, so every answer in it has to be one support has really given.

A ticket that is still open has no settled answer, and a ticket closed
as wontfix describes something the product does not do. Neither belongs
in a document customers read as "how it works".

Where two tickets are the same question, the second one carries a
`duplicate_of` pointer at the first.
