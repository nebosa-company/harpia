# Rollup notes

Four regions, four spreadsheets, four sets of local habits. The rollup is
the only document the executive team reads, so the one thing it has to be
is arithmetically closed: every column adds up, and the rates are derived
from the counts rather than averaged.

The two traps that have bitten previous rollups are a region that prints
its own total inside the market table, and a region that reports money in
a different unit and says so only in a note above the table.
