# Review pack notes

Five quarterly reviews, each written by whoever had the pen that quarter,
each final once circulated. When a later review needs to restate an
earlier figure it is supposed to say so in words. Sometimes it just
quietly prints a different number, and that is exactly what this exercise
is looking for.

A metric moving between quarters is not a disagreement. A metric that has
two different values for the same quarter is.
