# Units notes

The incident that started this: a shipment total added kilograms to pounds
and nobody noticed for six weeks, because both were just numeric vectors.
Carrying the unit on the object and refusing to add across units is the
whole point — a loud error beats a plausible wrong number.

The print output is parsed by the shipping console's log scraper, so the
exact lines matter, down to the padding.
